# Student-Report-System
A frontend-based Student Report System for managing marks, attendance and academic performance.
🎓 Student Report System

📌 Project Overview

The Student Report System is a frontend web application developed to manage and display student academic performance in a simple and user-friendly way.

The system can be used to view student details, subject-wise marks, grades, attendance, teacher remarks, and overall academic performance.

---

🎯 Project Objective

The main objective of this project is to create a digital student reporting system that makes it easier to organize and monitor academic information.

It also helps demonstrate practical knowledge of HTML, CSS, and JavaScript.

⚙️ How to Run the Project

Method 1: Using a Web Browser

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html".
4. The Student Report System will open in your web browser.

Method 2: Using VS Code

1. Open the project folder in Visual Studio Code.
2. Open "index.html".
3. Use the Live Server extension.
4. Click Go Live.
5. The project will open in your browser.

📊 System Modules

1. Student Details

Displays basic information such as:

- Student name
- Student ID
- Department
- Year

2. Academic Performance

Displays marks obtained in different subjects and calculates the overall performance.

3. Attendance

Displays the student's attendance percentage.

4. Grade

The system can calculate grades based on the marks obtained.

Example:

Percentage| Grade
90–100| A+
80–89| A
70–79| B
60–69| C
50–59| D
Below 50| F

The grading scale can be customized according to the institution's requirements.

5. Teacher Remarks

Teachers can provide comments about the student's academic performance.

6. Performance Analytics

The system can display performance information using tables or charts to make academic progress easier to understand.
